# v1.3.2 Changelog

Date: 2026-08-10

## UI and workflow improvements
- Restyled the section/navigation tabs to dark navy with white text and 3D rectangular treatment.
- Restyled badges and status boxes with a raised 3D rectangle appearance.
- Improved multi-select filter dropdown layout and spacing for better density and readability.
- Added **Select visible** and **Clear visible** actions inside filter dropdowns so matching filtered items can be selected in bulk.
- Added **Close** and **Clear all** actions inside filter dropdowns.

## Measurement Period section
- Added **Rule effective date** and **App last updated** columns.
- Added a gold superscript star for states with a recent material update/change within the prior 12 months from the published baseline date.
- Added a legend chip showing the count of recently updated states.

## Research and Update section
- Strengthened the generated research prompt so threshold updates also instruct the reviewer to update all dependent fields used throughout Sections 1, 2, and 3.
- Added an on-screen prompt coverage note describing the dependent fields included in the update process.

## Rules/data status
- No audited jurisdiction threshold logic, measurement engine, or collection timing rules were changed from v1.3.1.
